# METAL CARDBOT — браузерная приключенческая игра (5+)

**Текущий статус:** инженерная демоверсия. Ветка `feature/m2-tech-forest-maze` добавляет первый проходимый лабиринт «Технолес» по Issue #9 (PR-A). Не финальная игра и не лицензированная игра по официальной франшизе.

## Как попробовать

1. Открой GitHub Actions → последний успешный запуск **Build & test** для нужной ветки.
2. В блоке **Artifacts** скачай `METAL-CARDBOT-offline-demo`.
3. Распакуй ZIP и открой `index.html` в Chrome / Edge с поддержкой WebGL2.
4. На стартовом экране нажми «Начать приключение» — это также разрешает запуск музыки в браузере.

## Что есть в этой сборке

- Процедурный оригинальный сине-бело-золотой робот и полицейский автомобиль с базовой анимацией. **Это не официальная 3D-модель Blue Cop**.
- Плавный разворот, анимированные локти и колени, складывание при трансформации, вращение колёс и световой эффект.
- 3D-лабиринт «Технолес» с двумя развилками, двумя переправами, секретной звездой, реактором, воротами, тремя энергоячейками и порталом. Правая переправа поднимается при приближении.
- Физические коллизии троп, деревьев, камней, лесных островов, воды и ворот; безопасные точки восстановления; камера останавливается перед крупными препятствиями.
- Цветные каналы питания и три узнаваемых ориентира помогают найти путь; каждый верно соединённый провод зажигает канал прямо в игровом мире.
- Автоматическая активация цветовой головоломки: соединить три провода с разъёмами подходящего цвета; ворота открываются в 3D-мире.
- Оригинальная синтезируемая музыка и эффекты; необязательные голосовые подсказки на русском.
- Тесты игровой логики и HTML-бандл без внешних JS/CSS.
- Автоматизированный браузерный сценарий клавиатуры, головоломки, части лабиринта и сенсорного управления; скриншоты PlayCanvas сохраняются в артефакт CI.

## Локальная разработка

Нужен Node.js 22+.

```bash
npm install
npm run dev
```

Проверка качества:

```bash
npm test
npm run typecheck
npm run build
npm run test:browser
```

Перед локальным браузерным тестом установи Chromium: `npx playwright install chromium`. Сборка `dist/index.html` является самостоятельным файлом благодаря `vite-plugin-singlefile`. Её также прикрепляет GitHub Actions к успешному запуску.

## Чего пока НЕТ

- Настоящего художественного GLB-ассета Blue Cop, полноценной кинематографичной трансформации и оригинальных персонажных анимаций.
- Десяти уровней, боссов, полноценной системы адаптивного обучения и финальной музыки.
- Доказанного FPS и полноценного визуального playtest на устройстве ребёнка. Скриншот CI проверяет технический путь, но не художественное качество.

**Следующие отдельные этапы:** качественная модель/риг с подтверждёнными правами, 30-секундное отполированное вступление и продвинутые анимации. План лабиринта и его технические ограничения описаны в [docs/08-maze-pr-a.md](docs/08-maze-pr-a.md).

## Права

METAL CARDBOT и Blue Cop — персонажи и название сторонней франшизы. Этот репозиторий не связан с правообладателями. В публичный репозиторий не добавляются официальные 3D-модели, логотипы или аудиоматериалы без разрешения. Все текущие временные художественные решения оригинальны.
