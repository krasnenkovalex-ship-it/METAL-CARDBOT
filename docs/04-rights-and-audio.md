# Intellectual property and music
This repository is public. METAL CARDBOT is the working project name referencing a third-party property; this work has no affiliation with its rights holders.
- Never commit extracted frames, game rips, original character models, brand marks, dialogue clips or licensed songs without proof of rights.
- For a public demo, prefer an original robot/vehicle identity and original music.
- A user-provided legally usable soundtrack is allowed as a private runtime import; do not commit it by default.
- Before publishing an Instagram reel with licensed music, verify permitted usage on the platform for that account and region.
- The asset register must include creator, rights owner, license scope, and confirmation of promo/redistribution permission.
