# METAL CARDBOT 2D — first-level visual milestone
## Status
Original vector-based art pack + upgraded first playable mission. The hero in these files is an **original blue-white police robot**, not an official licensed Blue Cop illustration. A rights-cleared franchise-character sprite atlas is a separate, blocked production task.
## What was added
- Local SVG assets: atmospheric sky, mid-forest, foreground foliage, robot and police car, stone/grass platform.
- Three parallax depths, richer menu, foreground scenery and art-based platform tiles.
- Two proximity-triggered puzzles: alternating colors, counting batteries. Solutions activate bridge and generator/gates.
- Transform animation, camera follow, energy crystals, soft hazards and checkpoint-based recoveries.
- Original synthesized melody/SFX from the user start gesture, large victory screen.
## Production next
- Art: licensed character atlas, authored 12-frame run cycle, jump, fall, landing, 16-frame transformation, car wheels and VFX.
- Mechanics: real enemies, educational in-world physics puzzles, accessible touch QA.
- QA: desktop Chromium complete first-level run including all collectibles, mobile landscape, 30/60fps measurements on named devices.
- Campaign: 10 levels are outlined, only stage one playable in this milestone. Bosses on 3/6/9 are not shipped.
## Requirements for acceptance
No visual placeholder should be called a finished illustration. Every linked asset must be present in repository and have clear provenance. All animations, level mechanics and builds must be verified before merge. Public promotional use of Metal Cardbot trademarks/characters/audio requires clearance.
