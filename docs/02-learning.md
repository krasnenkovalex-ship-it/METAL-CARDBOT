# Learning design and challenge bank
## Requirements
- Ages 4–6, center on age five.
- Tasks start automatically inside an interactive radius with a 0.2–0.4-second dwell.
- Only one task at a time. Solved tasks do not retrigger; dismissed tasks wait for leaving and returning.
- Automatic voice prompt is optional; always provide pictograms and replay.
- Avoid quizzes as the dominant mechanic: use draggable objects, switches, physical puzzles, matching, sorting and path planning.
- Wrong choice: specific gentle hint, no score penalty and no timeout.
## Initial task families
| Skill | Interactive action | World consequence |
|---|---|---|
| Colors | Connect glowing wires to matching ports | Power bridge |
| Working memory | Repeat 2–4 lamp flashes | Open lift |
| Logic | Complete a gear pattern | Restore rotating machine |
| Counting | Load 3–20 energy cells | Launch vehicle |
| Spatial skills | Rotate mirrors in light maze | Lower shield |
| Language | Identify initial phoneme or respond to NPC | Rescue friend |
| Flexible thinking | Sort by shape then by color | Disable traps |
| Planning | Choose route past obstacles | Move walls |
## Difficulty
Start 1–5 quantities, 2-item memory sequence and obvious contrasts. Increase only after repeated independent successes; offer selectable easy mode at any time.
## Progress tracking
Count independent solve / hint used / task abandoned for parental review; no child account or analytics upload. Store progress locally only after parent approval.
