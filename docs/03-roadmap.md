# Delivery plan / GitHub milestones
## M0 Repository foundation (current PR)
- Source structure, clean README, CI, typed proximity trigger, unit tests, original placeholders.
- Acceptance: git commit, CI green, Vite build passes, one auto-trigger demonstrated.
## M1 First impressive 30 seconds
- Original art brief, robot mesh and vehicle, rig, idle/run/jump and transformation, matching camera and SFX.
- Acceptance: recorded 30-second playable segment on desktop, no placeholder hero geometry.
## M2 Living forest
- Modular kit, three recognizable landmarks, maze signs, collectibles, moving props and checkpoints.
## M3 Interactive learning
- Three distinct world-native puzzle mechanics, voice prompts and nonpunitive hint system.
## M4 Enemy and boss
- Three predictable actions, warning animations, safe recovery, environment-based boss shield.
## M5 Production polish
- 30/60 FPS target validation on named devices; QA, keyboard/touch, sound, save, accessibility and parent review.
## M6 Showcase
- Tested shareable deployment, real gameplay trailer, cleared original music and rights-reviewed art.
## Scope guard
Do not implement ten superficial levels before M1–M3 are verified. No success claims based on automated browser scripts alone.
