# Art direction: 2026 stylized 2D action platformer
The aesthetic target is polished 2.5D adventure: three+ layered parallax backgrounds, readable silhouettes, hand-painted forest and futuristic ruins, restrained bloom and light particles.
**Temporary engineering art is NOT accepted as final work.**
Character deliverables: authored atlas PNG/WebP+JSON (idle 8-12, run 10-16, jump 4-6, land 4-6, transform 12-20, car drive 8-12, victory 8+). The animation must be expressive, with consistent ground contact.
Map kit: sky/far/mid/foreground, animated bridges/gates, collectible and boss sprite atlas, 64-128px collision tilemap, parallax and UI style guide.
Use *original or licensed* assets with creator/source/license/permitted game and promo uses recorded. Blue Cop likeness requires rights if released or promoted publicly.
First visual acceptance: record 30 seconds in 1280×720 from a running build, not a concept illustration.
